本工具在浏览器中分析本地音频 不上传用户录音 不提供任意乐器的准确识别保证 不自动将混音分离为独立乐器

声学测量与乐句候选为数学估计 自动对白使用有限的中英话语素材与乐句规则 不调用语言模型 不构成对音乐语义的客观解码

Discogs EffNet 编码模型与MTG Jamendo Instrument 模型由 Universitat Pompeu Fabra Music Technology Group 发布 原始模型与元数据完整附于 models 目录 原始许可文件与官方模型许可说明保持原文 供核对非商业使用条件

音频前端依据 Essentia 的 MusiCNN 规范 使用 16 kHz 采样率 512 点 Hann 窗口 256 点步长 96 个 Slaney Mel 频带 与 log10 压缩 系数由官方 Essentia 实现导出

本工具代码依据 AGPL-3.0 开放 页面使用未压缩的 ES 模块 应用源码 对白与文件格式 信号前端 模型调用 项目存储 离线缓存

ONNX Runtime Web 1.30.0使用 MIT 许可 许可原文

Phosphor Icons 2.1.2使用 MIT 许可 许可原文

Mediabunny 1.61.5用于逐帧 MP4 封装 使用 MPL-2.0 许可原文 视频导出源码

模型排序是未经校准的分数 不代表统计置信度 乐句步长为 20 毫秒 不等于识别误差为 20 毫秒 浏览器实时视频导出也受设备性能与浏览器编码支持限制
