# 音乐翻译器

制作者 / 姜昕宇

[打开网页](https://13864768492jxy-create.github.io/music-translator/)

从音色与乐句出发创作中英双语对白 支持本地音频导入 作品保存 字幕与视频导出

页面内有《两个吉他的对话》和《先给自己十分钟》两段已完成的视频示例

访客导入的音频与项目只保存在自己的浏览器中 不上传 不自动同步设备

人物与对白属于艺术解释 乐器识别与乐句边界是可修订的模型和测量结果

网站文件完整保存在 site/ 不依赖其他托管平台运行 修改后由 GitHub Pages 自动发布
